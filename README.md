# MERN Product Store

A full-stack product-store application demonstrating modern MERN architecture, catalog browsing, and end-to-end commerce workflows.

## Features

- Product catalog and product details
- Shopping and store-oriented user interface
- Separate client and server applications
- RESTful backend architecture
- MongoDB-backed application data

## Technology

- MongoDB
- Express
- React
- Node.js
- JavaScript and CSS

## Getting started

Install dependencies for the server and client, configure environment variables, and start both applications using the available package scripts.

```bash
npm install
npm run dev
```

Never commit database credentials or private API keys.

## Status

Educational and portfolio full-stack project demonstrating MERN application structure.
